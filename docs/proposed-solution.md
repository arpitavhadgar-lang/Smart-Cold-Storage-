# Proposed Solution

The proposed system is a Climate-Adaptive Solar Smart Mini Cold
Storage that uses solar energy, battery storage, smart sensing and
energy-efficient DC cooling.

The system first utilizes passive cooling and thermal insulation to
maintain suitable storage conditions. When the temperature rises
above the defined threshold, the ESP32 activates the cooling system.

The storage chamber can be divided into multiple compartments so
that different vegetables can be stored according to their
temperature requirements.
