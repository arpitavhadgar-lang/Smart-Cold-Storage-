# Software Technologies

The software technologies used in the Climate-Adaptive Solar Smart Mini Cold Storage system are:

## 1. Arduino IDE
Used for programming and uploading the control program to the ESP32 microcontroller.

## 2. Embedded C/C++
The ESP32 control logic is developed using Embedded C/C++ programming.

## 3. ESP32 Programming
ESP32 is programmed to monitor sensor data and control the cooling system based on predefined temperature conditions.

## 4. Sensor Monitoring
The software continuously reads temperature and humidity sensor data to monitor the storage environment.

## 5. Threshold-Based Control
The control program compares the measured temperature with predefined threshold values and activates or deactivates the cooling system accordingly.

## 6. Serial Monitor
The Arduino IDE Serial Monitor can be used to display sensor readings and system status during testing and debugging.

## 7. Data Logging and Analysis
Temperature and humidity data can be recorded and analyzed to evaluate the performance and energy efficiency of the system.
